Licence key generator

Creates the signing key pair for your licence script. Everything happens in this page, on this computer. Nothing is sent anywhere.

Run this once and keep the private key secret. Anyone with it can create valid licences. If you lose it, you must make a new pair and update every app.

1. Private key (secret)

Paste into the licence script: Project Settings, Script properties, add a property named PRIVATE_KEY. Keep a copy somewhere safe and offline.

2. Public key (safe to share)

Paste into config.js as licPub. It goes into the app, and it can only check licences, never make them.
